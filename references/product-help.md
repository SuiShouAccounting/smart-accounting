# 产品帮助子场景

## 何时读这个文件

当用户询问随手记 / 神象云 App、小程序、网页版的功能使用问题时阅读此文件。包括：
- 用户说"怎么用随手记"、"怎么用神象云"、"功能帮助"
- 用户问具体功能操作：如"怎么设置预算"、"怎么删账本"、"怎么转让账本"、"怎么换手机号"、"账本同步出问题怎么办"、"数据找不到了"
- 用户问 App / 小程序 / 网页版的区别或入口

> 内容来源：官方产品手册《随手记-用户功能手册》（33 篇）。**回答产品使用问题时只依据本文件**；本文件没有的功能，回答"这个功能我这边暂时没有说明"，并建议用户在 App 内「求助反馈」找客服，**不要编造操作路径**。

## 回答规范（重要）

1. **只答本文件内容**：操作路径按原文输出（如「我的」页面 →「设置」→ …），不改顺序、不省略关键步骤
2. **会员/费用信息如实告知**：涉及香蕉贝、会员权益的说明（如恢复账本 6 贝、跨账本功能需基础会员）必须带上
3. **图片与教程链接**：用 `[查看图片](url)` / `[查看图文教程](url)` / `[观看视频教程](url)` 的形式输出，供用户点击打开；如果当前客户端无法打开链接，就只给文字步骤，**不要把原始 URL 直接贴给用户**
4. 不同平台（iOS / 安卓 / 鸿蒙 / 小程序 / 网页版）入口可能不同，用户说明了平台就按对应平台的步骤回答

## 帮助流程

### Phase 1: 理解用户问题
- 分析用户具体问的是哪个功能（对照下方「功能手册」分类定位）
- 问题模糊时，先确认：哪个功能、什么设备（App / 小程序 / 电脑）

### Phase 2: 提供帮助内容
- 按手册原文给出功能入口、操作步骤、注意事项（会员要求、平台限制）

### Phase 3: 确认是否解决
- 简短询问是否解决；未解决则细化问题再答，或引导 App 内「我的」→「求助反馈」→「客服」

# 功能手册

## 一、账本管理

### 新建账本

- **入口 1**：App 首页 →「新建账本」→ 选择账本模板 → 点击「+」添加
- **入口 2**：App 首页 → 底部「账本模板」→ 挑选模板 → 点击添加（或进模板详情页添加）
- 随手记共支持免费创建 **28 个**账本：神象云账本 **3 个**、随手记账本 **25 个**，超过对应数量后需付费
- **超量规则**：
  - 神象云账本：免费 3 个，超出后需「基础会员及以上」，或每新建 1 次消耗 1 香蕉贝
  - 同步账本（原随手记账本）：免费 25 个，超出后需「基础会员及以上」
- 随手记账本在「账本模板」页面底部「随手记账本」推荐专区，支持家庭账本、标准账本、基础账本三类；神象云小程序与鸿蒙版 App 暂不支持该功能
- [查看图片](https://oss.feidee.com/oss/vesop_8cb5cc34ddac8135_3840X2316.png)　[查看图片](https://oss.feidee.com/oss/vesop_c3e811221b99a2d5_3840X2316.png)

### 神象云账本与同步账本的区别

神象云账本是新开发的云端账本，相较传统随手记账本（现称同步账本）在以下方面显著升级：
- **设计风格**：界面更简洁、操作更直观
- **记一笔键盘**：支持多种键盘样式
- **成员角色与权限管理**：精细化角色权限分配，适合团队、经营人群多人记账
- **账本数据管理**：操作日志、流水回收站、封账等，适合生意场景

注：鸿蒙 App 仅支持使用神象云账本。
[观看视频教程](https://videos.feidee.com/activity/202210/FUhqXDWNNpeby9v2.mp4)

### 账本模板选择

随手记支持包括个人、家庭、生意在内的 **100 种以上**账本模板，一个账本对应一个独立记账场景。常见选择：

| 人群/场景 | 推荐账本 |
|---|---|
| 家庭与生活管理 | 家庭账本、攒钱账本、宝宝/儿童教育账本、家庭装修账本 |
| 个人财务与收入 | 白领/懒人账本、副业专项账本（网约司机、摄影摄像等）、房东账本、大学生/单身账本 |
| 生意与经营核算 | 生意账本、餐饮生意账本、服饰/零售生意账本、淘宝/微商生意账本、建筑工程/装修队长账本（多店经营建议每家分店建独立账本） |
| 短期专项与兴趣 | 结婚账本、旅游账本、健身账本、合租账本、追星/宠物/医美账本 |

建议不要将不同性质的收支混记于同一账本。

### 删除账本与恢复账本

- **删除**：「我的账本」→ 选账本 →「...」→「删除账本」。已绑定手机登录用户首次删除需短信验证码或登录密码校验（15 分钟内删过一次则免重复验证）；未绑定手机号需先绑定
- **恢复**：**7 天内**删除的神象云账本和随手记账本均可在「我的」→「**账本回收站**」→ 选中账本 →「...」→「恢复」。恢复账本是增值功能，消耗 **6 香蕉贝**（开通基础会员可免）；神象云账本恢复后账本内香蕉贝、购买套餐等同步恢复；鸿蒙不支持扣贝恢复，需开通会员；神象云小程序用户需下载 App 操作

### 将账本转让给他人

作为账本创建者（账本主人），可将账本转让给账本内的其他成员。
- **神象云账本**：进入账本 → 右上角头像 →「成员与角色管理」→ 顶部「角色管理」→「账本主人」→「转让」。最后确认需输入个人账号密码；转让完成后原主人角色变为「管理员」，账本仍显示在其账本列表中（状态仍为「我创建」）。鸿蒙 App、神象云小程序暂不支持
- **同步账本**：老账号进入本地账本 →「设置」→ 顶部「>」→ 分享栏「账本」→ 通过微信/QQ 分享；新账号点击分享链接 → 浏览器打开 → 选择「随手记」→ 登录新账号即可看到账本（同一手机操作时需先登录旧账号分享，再登录新账号点击链接）
- [查看图片](https://oss.feidee.com/oss/vesop_ef3a19ba5c93fa41_3840X2316.png)　[查看图片](https://oss.feidee.com/oss/vesop_35a9b2aaa68a9a1d_3840X2316.png)

### 账本结转

本期（年/月）结束将原账本的账户余额等数据结转至一个新账本（一般年底/月底操作），结转后生成新账本，老账本不受影响、可继续记账。
- **自动复制**：账户及余额、收支分类、项目/商家/虚拟成员/借贷人、未结清的借贷流水
- **可手动选择**：指定日期之后的流水、真实成员及角色、账本香蕉贝余额（转移而非复制）
- **暂不支持**：账本内套餐、记一笔及流水设置
- **入口**：打开账本 →「设置」→ 底部「账本结转」→ 选择结转时间、新账本名称等 →「开始结转」。属会员功能，需基础会员或「账本高级功能」（1 贝/天，可关）。神象云小程序暂不支持
- [查看图片](https://oss.feidee.com/oss/vesop_e9a04dcbde64a31c_3840X2316.png)

- **全量同步操作**：

## 三、记账与预算

### 预算管理

- **入口**：进入账本 → 顶部导航栏「预算」→ 选择预算「时间维度」→ 选择「预算类型」→ 点进预算科目 → 设定一级和二级预算数值　[查看图片](https://oss.feidee.com/oss/vesop_17f5c4e262ec3b12_3840X2316.png)
- **预算类型**：
  - 支出预算：所有标记为"支出"的流水自动汇总统计
  - 收入目标：所有标记为"收入"的流水自动汇总统计
  - 按标签设置：分类预算/目标、账户预算/目标、成员预算/目标（谁花的）、商家预算/目标（在哪买的）、项目预算/目标（为了什么事）　[查看图片](https://oss.feidee.com/oss/vesop_79e1f6ec2752d6fa_3840X2316.png)
- **时间周期**：天/周/月/季/年预算（目标）。上方「月」切换周期；页面向下拉看历史周期，拉到最底部向上拉进入下个周期　[查看图片](https://oss.feidee.com/oss/vesop_4a9bb0f6e6d55442_3840X2316.png)
- **预算提醒**：开支≥预算 90% 时每新增一笔开支收到预警提醒；≥100% 时收到超支提醒。入口：App 首页（非账本内）→ 右上角「消息入口」→ 右上角「设置」→「预算预警提醒」→ 打开　[查看图片](https://oss.feidee.com/oss/vesop_88f7dcf17c56707f_3840X2316.png)

## 七、常见问题

### 找不到账本 / 数据没了怎么排查

神象云账本数据均加密存储云端，一般不会丢失。常见原因依次检查：
1. **账本未同步至登录账号**：神象云账本可退出当前账号登录，看账本是否显示在未登录状态，需要则重新登录迁移；老随手记账本检查登录状态是否失效，尝试重新登录
2. **登录态失效 / 网络异常**：App 请求账本列表未拉到数据 → 重新登录；网络波动 → 下拉刷新账本列表；服务超时（发版/服务器异常）→ 稍后重试刷新
3. **误登其他账号**：手机号、微信等不同方式登录可能创建了 2 个账号，数据互相独立，确认当前登录账号是否正确
4. **未登录状态下记过账**：退出登录后刷新「我的账本」查看未登录状态的账本
5. **刷新账本列表**：「我的账本」页面下拉刷新，或关闭 App 重开

仍未找回：「我的」页面 → 下滑「求助反馈」→「客服」，提供信息由客服协助定位恢复。

### 首页数据都是 0 怎么办

- **首页账本卡片周期**：首页常显示"本月""本年"，上月记账而本月未记账时本月卡片为 0，可到「流水」「报表」页面查看
- **检查登录情况**：当前是否登录、登录的是否是常用账号
- **检查是否进错账本**：多个账本时确认进的是哪个

未解决可「我的」→「求助反馈」→「客服」　[查看图片](https://oss.feidee.com/oss/vesop_315a0886614bb506_3840X2316.png)
