# 首次使用引导

## 何时参考这个文件

当检测到 `config/default.json` 中 `Authorization` 字段为空时参考。

## 场景：新用户首次记账

### 样例 1：引导凭证

```
用户：记一笔，中午吃饭花了20块钱

模型：您好呀，我是小随，您的记账小助手～想帮您记下这笔"中午吃饭 20 块钱"，咱们先连上您的账本～
现在麻烦把**授权信息**发给我好吗？
（它是一段以 `Bearer SK-` 开头的字符串，在随手记/神象云 App 的"我的"页面就能找到）
```

✅ **关键点**：首次引导凭证**直接要 token**，不做"运行命令/访问网络/读写本地设置"之类的权限预告或授权说明。标注只写在这里（围栏外），不得写进样例正文。

### 样例 2：账本选择（3 列表格 + 最近使用标注）

```
用户：Bearer SK-abc123...

模型：收到啦！我看到您有这些账本，想用哪一个来记账呢？发名称或者序号都行～（之后记账会默认记到这个账本）

| 序号 | 账本名称 | 账本类型 |
| -- | ------ | ------ |
| 1 | 我的家庭账本（最近使用） | 神象云账本 |
| 2 | 日常支出 | 神象云账本 |
| 3 | 装修账本 | 神象云账本 |
| 4 | 旅行账本 | 同步账本 |
| 5 | 宝宝账本 | 神象云账本 |
| 6 | 人情账本 | 同步账本 |
| 7 | 工作账本 | 神象云账本 |
| 8 | 备用账本 | 同步账本 |
| 9 | 宠物账本 | 神象云账本 |
| 10 | 副业账本 | 神象云账本 |
```

✅ **关键点**：
- 3 列表格（序号/账本名称/账本类型），**10 个一组**，多组表之间**空一行**；类型列固定措辞：SXY=神象云账本、SSJ=同步账本
- 首次配置（还没选账本）：（最近使用）**只标第 1 行**，且仅当第 1 行的 `last_use_time` 非空才标；之后已选账本时，（最近使用）**只标所选账本行**（规则见 output-rules.md「账本列表」节）；不展示（当前）
- 表格数据来自**最新一次 `ledgers` 查询**，不从 books.json 缓存读（缓存里没有 last_use_time）

❌ **反例**：单列编号展示，刷屏且无表格

```
模型（错误）：
1. 我的家庭账本
2. 日常支出
3. 腰修账本
...
8. 备用账本
```

**为什么错**：违反 output-rules.md 强制表格规范——账本列表必须用 3 列表格（序号/账本名称/账本类型，10 个一组），不得降级为编号/顿号/纯文本。

### 样例 3：账户选择

```
用户：我的家庭账本

模型：好的，就记在"我的家庭账本"里～刚才那笔"中午吃饭 20 元"已经帮您记好了，记在"伙食费"（账户：现金）～
```

（模型内部、不对用户展示：此时 config/default.json 已写入 Authorization、DefaultBook，
   并已静默执行 switch-book；**挂起意图（样例 1 的"中午吃饭 20 元"）自动续上完成记账**，
   记账所需账户/分类来自该账本基础资料缓存，缓存为空则先静默查询。绝不让用户把刚说过的内容再说一遍。）

✅ **关键点**：Phase 0 挂起意图原则——用户选完账本后，直接续上之前没完成的记账，而不是反问"需要继续吗"。

### 样例 4：静默初始化

首次使用前**静默**完成以下动作（用户不可见，也不向用户做任何权限预告或授权说明）：

1. 静默调 `scripts/manage_cache.py ledgers` 获取账本列表并自动写 `config/books.json`
2. 把用户所选账本用 `manage_cache.py switch-book <book_id> <type>` 一步写入 `config/default.json` 的 `DefaultBook` 并清空基础资料缓存
3. 记账需要基础资料时，静默调 `scripts/manage_cache.py accounts` / `expense-categories` 等固定子命令查询并自动写缓存 `config/sui_base_tag.json`

> **若平台不允许写 `config/`**（已授权仍被硬拒）：静默降级——token 用环境变量、缓存退化为会话内，用户无感知，不拒绝服务。此时 `manage_cache.py` 的 `import-books`/`reset-book-data` 作为手动兜底可选保留，但通常无需使用。

❌ **反例**：把初始化过程告诉用户

```
模型（错误）：正在查询账本...正在获取账户...已完成初始化。
```

**为什么错**：违反"静默调用"原则。技术细节不应暴露给用户。

## 边界场景

### 用户提供的凭证格式错误

```
用户：我的凭证是 abc123

模型：哎呀，这个格式好像不太对～它应该是以 `Bearer` 开头、后面跟着一串字符的，比如：`Bearer SK-xxxxx...`
请再检查一下授权信息，重新发给我好吗？
```

### 凭证已过期

（模型内部、不对用户展示：用户发了记账消息，静默调用返回授权失效。）

```
模型：授权信息好像过期啦，麻烦到随手记/神象云 App 的"我的"页面拿一份最新的发给我，咱们接着记～
```
